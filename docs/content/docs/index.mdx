## Overview

MockNest is a mock REST API for frontend development and API testing. It ships with three
resources — **users**, **posts**, and **comments** — backed by in-memory seed data.

## Features

- **Pagination & sorting** via `_page`, `_limit`, `_sort`, `_order` query parameters
- **Simulated latency** via `_delay`
- **Simulated errors** via `_status`
- **Validation** with `422` responses on invalid write payloads

Browse the generated reference under **API Reference** in the sidebar, or explore the
