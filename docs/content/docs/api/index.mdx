## API Reference

Interactive documentation for every MockNest endpoint, generated from the
OpenAPI specification. Use the sidebar to navigate each resource — **users**,
**posts**, and **comments** — and each HTTP operation (GET, POST, PUT, DELETE).

Every operation page includes:

- Request and response schemas
- Reusable query parameters (`_page`, `_limit`, `_sort`, `_order`, `_delay`, `_status`)
- **Try it out** — send real requests to the running API and see live responses
